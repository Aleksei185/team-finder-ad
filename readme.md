# TeamFinder

Платформа для поиска единомышленников и совместной работы над pet-проектами.  
Разработчики, дизайнеры и другие специалисты могут создавать проекты, находить команду и откликаться на предложения.  

**Вариант 2** — управление навыками пользователей и фильтрация участников по навыкам.


# Функциональность

- Регистрация и аутентификация (email + пароль)
- Публичный профиль пользователя: аватар, контакты, описание, список проектов
- Управление навыками (добавление / удаление, автодополнение, создание новых навыков)
- Создание, редактирование, завершение проектов
- Участие в проектах (присоединиться / отказаться)
- Главная страница со списком проектов (пагинация 12)
- Список пользователей с фильтрацией по навыкам (пагинация 12)
- Админ-панель для управления пользователями, навыками и проектами


## Стек технологий

- **Python** 3.10+
- **Django** 5.2
- **PostgreSQL** (в Docker-контейнере)
- **Docker** / **Docker Compose**
- **Pillow** (генерация аватаров)
- **pytest** / **pytest-django** (тестирование)
- **python-decouple** (переменные окружения)

## Установка и запуск (локальная разработка)

1. Клонировать репозиторий

git clone https://github.com/Aleksei185/team-finder-ad

2. Создать и активировать виртуальное окружение 

python -m venv venv
source venv/bin/activate             # Linux/Mac
source venv\Scripts\activate         # Windows

3. Установить необходимые библиотеки

pip install -r requirements.txt

4. Создать файл .env

cp .env_example .env

5. Запустить PostgreSQL через Docker

docker compose up -d

6. Выполнить миграции

python manage.py migrate

7. Создать суперпользователя

python manage.py createsuperuser

8. Запустить сервер

python manage.py runserver


## Переменные окружения (файл .env)

| Переменная | Назначение |
|------------|------------|
| `DJANGO_SECRET_KEY` | Секретный ключ Django (можно сгенерировать через `get_random_secret_key`) |
| `DJANGO_DEBUG` | Режим отладки (`True` для разработки) |
| `POSTGRES_DB` | Имя базы данных PostgreSQL |
| `POSTGRES_USER` | Имя пользователя PostgreSQL |
| `POSTGRES_PASSWORD` | Пароль пользователя PostgreSQL |
| `POSTGRES_HOST` | Адрес сервера БД (`localhost` для локальной разработки) |
| `POSTGRES_PORT` | Порт подключения к БД (по умолчанию `5432`) |
| `TASK_VERSION` | Номер варианта задания (определяет набор HTML-шаблонов) |
